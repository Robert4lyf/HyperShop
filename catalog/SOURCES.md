# Catalogue sources

| File | What | Source |
|---|---|---|
| `ingredients.csv` | The catalogue (source of truth) | Names: the most frequent NYT names (`top-names.csv`). UK names, aisle, staple flag, shopping unit, display policy, grams per cup, pack notes and synonyms: written by the agent (`src=agent-estimate`), for you to check in `REVIEW.md`. Rows you correct get `src=user`. |
| `top-names.csv` | Top 400 normalised NYT ingredient names | `tools/catalog/top_names.py` over the NYT ingredient-phrase-tagger snapshot (Apache-2.0, `LICENSE-NYT`, `NOTICE-NYT`) |
| `synonyms.csv` | Every key (name, plural, synonym) → id | generated by `tools/catalog/build_catalog.py` |
| `REVIEW.md` | Review sheet | generated by `tools/catalog/build_catalog.py` |
| `android/core/src/main/resources/catalog/catalog.tsv` | The app's copy, with `#version` (first 12 hex of the CSV's sha256) | generated by `tools/catalog/build_catalog.py` |

## Columns
- `id` — stable slug; the item's `mergeKey` is `cat:<id>`.
- `name`, `plural` — UK display names.
- `synonyms` — `|`-separated; US names (spec R5.2) and NYT variants.
- `aisleCode` — `AisleCode` (spec R9).
- `staple` — seeds the `Staple` table (pre-ticked "in stock"): salt, black pepper, olive oil, vegetable oil, water.
- `shoppingUnit` — what you pick up (each, bunch, pack, tin, bag…).
- `displayPolicy` — `count` (round up, produce to ½), `mass`, `volume`, `presence` (shown without an amount).
- `gramsPerCup` — lets volume and mass combine for this item.
- `packNote` — display-only pack size (about 20 items).
- `src` — `agent-estimate` or `user`.

Edit `ingredients.csv`, then run `python3 tools/catalog/build_catalog.py`.
`verify.sh` fails if the generated files are stale.
